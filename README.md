# Sistema de Ventas - Aplicación de Escritorio

Aplicación de escritorio desarrollada como proyecto principal del curso para la gestión de ventas, clientes y productos.

## Tecnologías utilizadas
* Java
* NetBeans IDE
* SQL Server (JDBC)
* Swing / JavaFX 

## Cómo ejecutar
1. Clona el repositorio y ábrelo en NetBeans.
2. Configura la conexión a tu base de datos local en la Clase ConexiónDB.java.
3. Ejecuta el proyecto principal.
